# Dependencies

This is a Next.js project. All dependencies are listed in `package.json`.

## Quick Setup

**Note:** This project uses Node.js/npm, NOT Python. You can remove the Python venv.

To install all dependencies, run:

```bash
npm install
```

## System Requirements

- Node.js 18+ (with npm)

After running `npm install`, you can:
- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm start` - Start production server
- `npm run lint` - Run linter
